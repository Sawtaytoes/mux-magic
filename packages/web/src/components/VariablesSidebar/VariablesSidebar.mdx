# VariablesSidebar

Persistent right-side view of the sequence variables and saved templates,
rendered as a `@charcuterie/ui` `Rail`.

## Responsive behavior

- **Below `md`:** relocates to a horizontally-scrolling strip (it is _not_
  removed from the DOM), so Variables and Saved Templates stay reachable.
- **At `md` and above:** a fixed-width column on the right. Its width is
  **user-draggable** (grab the handle on its left edge) and persisted to
  `localStorage`; the column is **sticky** beneath the header and scrolls its
  own overflow, so a long variable list never runs off the bottom of the
  viewport or scrolls out of view with the sequence list.
