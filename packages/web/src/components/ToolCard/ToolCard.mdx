# ToolCard

A single destination tile on the `/` tool picker (`HomePage`). The whole card is one `<a>`, so the entire surface is the click target and the title is the accessible link text.

Presentational only — no atoms, no data fetching. The icon is passed in as JSX so the caller owns its size and color.

## Props

| Prop | Type | Role |
|------|------|------|
| `href` | `string` | Destination path (`/builder`, `/jobs`) |
| `icon` | `ReactNode` | Glyph rendered left of the title. Pass `aria-hidden` SVG; the caller sets the color class |
| `title` | `string` | Card heading, rendered as an `<h2>` |
| `description` | `string` | One or two sentences explaining what the tool does |
