# MonitorIcon

A 16×16px monitor SVG icon. The **system**-mode glyph for the header colour-scheme switcher (`<ColorSchemeSwitcher>`) — the mode that follows the OS `prefers-color-scheme`. Inherits `currentColor` stroke so it respects the parent text color.
